Effective-learning through improved prompt design

  • Tech Stack: Fewshot-prompting, GPT-API, NextJS, JavaScript, MOngoDB, TailwindCSS
  • Website URL: effective-learning-nu.vercel.app

Developed a research data collection website utilizing few-shot prompting to gather user responses and feedback for studying effective learning through improved prompt design.

The website is designed to collect user responses and feedback on various prompts, enabling researchers to analyze the effectiveness of different prompt designs in enhancing learning outcomes. It employs few-shot prompting techniques to guide users in providing meaningful input, thereby facilitating a more structured and insightful data collection process.
