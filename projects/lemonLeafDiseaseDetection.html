Lemon Leaf Disease Detection

  • Tech Stack: Fine Tuned Yollow Model, Roboflow, NextJS, Dataset, Notebook, Kaggle
  • Website URL: lemon-leaf-diseases-detection-ai.vercel.app
  • Github URL: Project Link

The Lemon Leaf Disease Detection is a web application that uses a fine-tuned YOLO model to detect diseases in lemon leaves. The application is built using Next.js and utilizes the Roboflow platform for model training and deployment. The dataset used for training the model is sourced from Kaggle, ensuring high-quality data for accurate disease detection.

The application allows users to upload images of lemon leaves and receive real-time predictions on whether the leaves are healthy or affected by diseases. The fine-tuned YOLO model ensures high accuracy in detecting various diseases, making it a valuable tool for farmers and agricultural professionals.
